# Verhaltenskodex / Code of conduct

**Deutsch**

Dieses Projekt soll ein freundlicher Ort für alle sein, die Home Assistant und Smoobu nutzen – egal wie viel Erfahrung jemand hat.

- Sei respektvoll und geduldig, auch bei Fragen, die schon beantwortet wurden.
- Kritisiere Code und Ideen, nicht Menschen.
- Keine Beleidigungen, Belästigung, Diskriminierung oder persönlichen Angriffe.
- Keine privaten Daten anderer veröffentlichen – das gilt ausdrücklich auch für Gästedaten aus Smoobu.

Verstöße bitte über die GitHub-Funktion **„Report content“** (⋯ an Kommentar oder Issue) oder **„Report abuse“** melden. Der Maintainer kann Beiträge bearbeiten, ausblenden oder löschen und Personen vom Projekt ausschließen.

**English**

This project aims to be a friendly place for everyone using Home Assistant and Smoobu, whatever their experience.

- Be respectful and patient, also with questions that have been answered before.
- Criticise code and ideas, not people.
- No insults, harassment, discrimination or personal attacks.
- Do not publish other people's private data – this explicitly includes guest data from Smoobu.

Please report violations with GitHub's **"Report content"** (⋯ on a comment or issue) or **"Report abuse"**. The maintainer may edit, hide or delete contributions and block people from the project.

Angelehnt an den / Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
